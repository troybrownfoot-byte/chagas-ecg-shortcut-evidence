## Disclosures (adaptivity)
- Length on test before TEST_A: read 1 (10-18) reported, as secondary endpoints, V3 by recording-length stratum (e.g. 12-lead ResNet V3 .553 for 7.3-s vs .705 for 10.2-s records) and V3 after a central 7.335-s crop (12-lead .503 -> .546). So the length effect had been seen on the test split (V3 only, ResNet models, central crop of the preprocessed signal) before the length-prevalence association was measured on val (10-23) and before crop-then-preprocess was specified on val. TEST_A's endpoints (V2, length-stratified V1) and models (A0, CinCo) had not been evaluated with any crop on test before.
- Demographics on test before any DEM test: read 2 (10-19) tested age/sex added to a ResNet (V1 +.004, replicated). A later DEM test confirmation would therefore not be the first test-split look at demographic inputs.
- Early exploration scripts (10-13/14: chagas_step2 train_eval.py, chagas_step6 train_eval_v2.py, chagas_step7 evaluate_step7.py) contain test-evaluation code paths; no output files of such runs were found, so they are not counted (cannot be fully excluded).
- Literature: adaptive reuse can invalidate holdout guarantees in principle (Dwork et al., Science 2015); empirical re-tests found little adaptive overfitting relative to distribution shift (Recht et al., ICML 2019; Roelofs 2019). The main remaining limitation is external validity (all positives from Brazilian cohorts; no external test set).
